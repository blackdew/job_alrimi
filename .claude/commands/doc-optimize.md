# 문서 최적화

doc-optimizer agent를 사용하여 프로젝트 문서를 현재 상태에 동기화한다.

## 원칙

- **정확성**: 코드와 문서 불일치 즉시 수정
- **최소화**: 문서 수와 양을 최소로 유지. 중복 제거
- **작업 로그 금지**: 변경 이력, 작업 일지 기록하지 않음

## 점검 대상

1. `CLAUDE.md`: 프로젝트 구조, 기술 스택, 개발 명령어가 현재와 일치하는지
2. `docs/` 내 문서: 불필요한 문서는 통합 또는 삭제 제안
3. 열린 이슈 상태와 문서 내 상태 표기 일치 여부

## 동기화 항목

- 디렉토리 트리 구조
- 기술 스택 표
- 개발/빌드/배포 명령어
- 크롤링 대상 URL 목록
- 환경변수 목록

## 규칙

- 문서 변경도 이슈 기반 커밋. 이슈가 없으면 생성
- 포맷팅만 변경하는 커밋 금지
- 문서 삭제는 사용자 확인 후 진행
